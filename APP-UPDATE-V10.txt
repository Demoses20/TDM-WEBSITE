TDM Manufacturing App V10 – session/API/product-media fix

Changes:
- Restored the Supabase publishable key used by the known-good V6 build.
- Unified all customer-facing Supabase clients on one persistent auth storage key.
- Fixed login persistence across Home, Store, Cart, Service and Account pages.
- Add to Cart now requires the signed-in customer session and returns to Store after login.
- Cart count is tied to the logged-in customer cart and starts at 0 when empty.
- Store product media now accepts image_url/image/images/image_urls/media_urls/media/photos/photo_urls, including Supabase tdm-media public paths, with a fallback image.
- Updated service-worker cache version so installed PWA clients pick up the new files.
- Fixed an existing JavaScript syntax error on the Affiliate page.

Note: The Supabase key is a publishable/anon client key. Do not place a Supabase service-role secret in the website.
