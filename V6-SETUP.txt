TDM MANUFACTURING APP V6
========================

Main changes
------------
1. Bottom app navigation is now exactly 4 items: Home, Store, Service, Account.
2. Each bottom navigation item has a bordered app icon with a strong color when active.
3. Customer Account is now a dashboard with six separate destinations:
   - About
   - My Orders
   - Payment Center
   - Affiliate Marketing
   - Account Settings
   - My Cart
4. Those six pages do not open inside the dashboard; they open as separate app pages.
5. Customer profile settings include name, phone, address, password and profile picture.
6. Product details have their own page with multiple photos/videos and full description.
7. Admin product editor supports selecting multiple photos/videos for one product.
8. Product media is stored in the existing products.image_url field as JSON when multiple media files are used.

Supabase Storage setup
----------------------
Create a PUBLIC Storage bucket named:
    tdm-media

Allow authenticated admin/customer uploads to this bucket according to your Supabase Storage policies.

The app stores product media under:
    products/<product-id>/...

Customer profile photos are stored under:
    customers/<user-id>/...

Admin product workflow
----------------------
1. Log in to admin-orders.html.
2. Enter product information.
3. Select multiple images/videos in "Product Photos / Videos".
4. Click Publish / Save Product.
5. The product is saved first, then all selected media are uploaded.
6. Open the Store and click the product to see its gallery and description.

Important
---------
The browser file picker controls how many files can be selected at once. The app input is configured with multiple="multiple".
Large video files may be rejected by the configured 100 MB per-file limit.
