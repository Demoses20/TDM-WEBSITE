🚚 Shipping

Set the fees customers see before payment. Customers do not enter kilometres.

Default checkout fees

Default transportation = base fee + configured distance × per-km fee. For a customer, the distance comes from the matching delivery zone below, so there is no KM field on checkout.

Delivery zones / distance rules

Example: create a Lagos zone, set distance from the TDM base, and set its per-km rate. The customer only supplies their address/city/state; checkout matches the zone automatically.
