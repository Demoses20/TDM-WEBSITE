TDM Manufacturing V11 account fixes

1. Customer account dashboard now has a fixed bottom navigation:
   Home / Store / Cart / Service / Account.
2. Customer account helpers now include the shared local cart functions,
   so Payment Center no longer fails with "tdmReadCart is not defined".
3. Account About no longer calls an undefined pageInit() function.
4. My Orders no longer crashes when the optional tracking_number/payment_status
   migration has not yet been applied. Tracking/payment show a safe placeholder.
5. Notifications now gives a clear setup message if customer_notifications
   has not been created yet.

Database:
Run the supplied supabase-customer-account.sql once in the Supabase SQL Editor
to enable notifications, saved payment methods, affiliate tables, and optional
Orders tracking/payment columns.
