TDM MANUFACTURING V12.5 FINAL ADMIN + CHECKOUT FIX

1. Supabase SQL
- Open Supabase SQL Editor.
- Run the complete SUPABASE-V12.4-FINAL-FIX.sql included in this package.
- The file now includes the V12.5 patch at the bottom.
- Wait for the SQL to finish successfully.
- The verification query at the bottom should show customer_addresses, customer_notifications, shipping_settings, shipping_zones, affiliates, affiliate_products, affiliate_clicks, affiliate_commissions and affiliate_withdrawals.
- shipping_zones should contain the new distance_km column.

2. GitHub Pages
- Replace the old website files with the files in this package.
- Do not restore mixer.png or oven.png. They were intentionally removed so product images/videos are controlled from Admin Store.
- GitHub Pages may take a short time to update. The new service worker cache is V12.5.

3. Admin
Open admin-dashboard.html.
Login with the authorized admin account.
The dashboard now has separate pages:
- admin-orders.html
- admin-store.html
- admin-media.html
- admin-shipping.html
- admin-affiliate.html

Store: upload product photos/videos directly from a phone or computer, edit, publish/unpublish and delete products/media.
Media: upload/delete Store, Products and Promotions media and control the home banner.
Shipping: configure default fees and delivery zones. Set the configured distance from the TDM base for each zone. Customers never enter KM.
Affiliate: view participants, clicks, commissions, balances and withdrawal requests; update commission/withdrawal status and pay affiliates.

4. Customer checkout
- Cart -> Proceed to Checkout -> customer enters address -> shipping is calculated -> Proceed to Payment.
- Checkout no longer asks for KM.
- A matching shipping zone uses its configured distance and per-km rate automatically.
- If no zone matches, the default shipping rates are used.
- Order creation uses the database RPC and has a direct-insert fallback so the page does not remain on Creating order indefinitely.

5. Password
- Login has Forgot Password.
- Customer Settings has Current Password + New Password + Save New Password.
- The current password is verified by signing in with the account email before the new password is saved.
- Reset-password.html handles email reset links.

6. Affiliate links
- Every published product is automatically synchronized into affiliate_products by SQL trigger.
- Affiliate product links preserve the GitHub Pages path instead of using origin only.
- Public visitors can open affiliate links without being logged in.
- Affiliate clicks are logged by tdm_log_affiliate_click.
- Paid orders generate commissions.

7. Important
- Do not put a Supabase service_role key in these website files. The package uses the publishable key only.
- Keep the admin email in the SQL and admin-common.js consistent.
